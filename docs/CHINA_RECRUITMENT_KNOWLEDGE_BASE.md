# 国内企业校招时间知识库

## 数据边界

企业春招、秋招和实习招聘时间属于持续变化的信息，不进入通用 FAQ。知识库按
`企业 + 招聘届次 + 招聘批次` 保存独立文档，至少记录：

- 投递窗口；
- 面向的毕业时间范围；
- 当前或历史状态；
- 官方来源 URL；
- 知识库更新时间。

当前首批收录字节跳动、华为、腾讯、腾讯音乐娱乐和阿里巴巴的 7 个批次。没有
公开统一截止日时，数据明确写“以官网实时岗位状态为准”，不能推测日期。

## Agent 路由

```text
校招时间问题
-> search_china_recruitment_kb
-> 当前/历史批次过滤与排序
-> 有据自然语言生成
-> 展示企业官方来源
```

通用 FAQ 与招聘知识库相互独立：FAQ 当前包含 35 个规范答案和 110 个常见问法；
企业公告可以频繁更新，而不影响稳定 FAQ。

## 更新流程

1. 只采集企业官方招聘网站或明确可核验的权威发布。
2. 新一届公告新增记录，不覆盖上一届。
3. 更新 `updated_at`，并把结束批次标记为历史。
4. 执行公司名、届次、投递窗口和未知公司拒答测试。
5. 通过测试后发布，回答中继续提示投递前复核官网。
